These examples are ready-made setups you can hand to Curia and then tailor to how you actually work. Each one is a starting point, not a fixed feature: you set it up by asking Curia in plain language, and you refine it the same way over time.

Unlike the capabilities that ship switched on, these are opt-in. Pick the one that matches what you're trying to do, adapt the wording to your preferences, and let Curia run it.
