## Diagrams

- The diagram SVGs in `assets/` are generated by the scripts in `diagrams/`. Never edit a diagram SVG directly: change its script and run `python3 diagrams/build.py`. `diagrams/README.md` lists which script makes which file.
- Look at the result before you call it done. On macOS, `python3 diagrams/build.py --preview <dir>` writes PNGs that you can open and view; check for overlapping or clipped text.
- Keep each diagram consistent with its page: the same names, numbers and facts. When you change one, check the other, and update both the script's `DESC` and the page's `alt` text.
- Use the shared palette and shapes in `diagrams/kit.py`, and keep the meanings in the visual-language table in `diagrams/README.md` (teal chip = Curia's code, dashed = outside, and so on).
- Before committing, run `python3 diagrams/build.py --check`. Commit the script and the SVG together.
